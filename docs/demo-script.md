# Three-minute demo script

## 0:00–0:25 — Overview

Start on Overview. Point to the data-derived record count and sentiment split. Open the highest-ranked issue and explain that the score is composed from volume, customer impact, sentiment risk, and trend inputs.

## 0:25–0:55 — Evidence

Open Feedback Explorer. Search `search`, filter to negative records, open the source detail, and highlight the exact quotation. Add one manual feedback record to show the ingestion path.

## 0:55–1:20 — Prioritization

Open Issue Radar. Sort by priority, save an issue, and open the evidence drawer. Show that the issue is backed by source IDs and that the status is a workflow field rather than an AI-generated narrative.

## 1:20–2:05 — Counterfactual Issue Simulator

Open Simulator. Increase response-state clarity and search relevance. Compare baseline and projected rankings, call out rank movement, and read the contribution explanation. Say explicitly that the simulator is a reproducible directional estimate, not a causal forecast or promised financial return.

## 2:05–2:50 — Adaption Lab

Show the provider readiness indicator. Enter a real Adaption dataset ID, request an estimate, and then launch a run only if the API key is configured. Show dataset/run IDs and status polling. If the environment has no key, demonstrate the persisted `adaption_not_configured` receipt instead of inventing a metric.

## 2:50–3:00 — Report

Open Reports and download CSV or JSON. Close by stating that the report carries the same issue and evidence boundaries visible in the workspace.
